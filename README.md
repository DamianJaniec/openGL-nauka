# OpenGL — Nauka 🎨

Repozytorium dokumentuje moją przygodę z programowaniem grafiki w OpenGL przy użyciu C++.
Każdy branch to kolejny krok na tej drodze.

Do tej pory udało mi się opanować rysowanie prostych kształtów, pracę z kolorami
oraz nakładanie tekstur. W branchu `ćwiczenie1` postanowiłem zebrać całą zdobytą wiedzę
i zamknąć ją w jednym, obiektowym projekcie.

Projekt tworzony w Visual Studio z wykorzystaniem bibliotek **GLFW** i **GLAD**.
